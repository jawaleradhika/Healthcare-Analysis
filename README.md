# Healthcare Analytics Database

A SQL-based Healthcare Analytics Database designed to manage and analyze healthcare information including departments, doctors, patients, appointments, bills, and medications.

## 📌 Project Overview

This project demonstrates how SQL can be used to create and manage a healthcare database and perform meaningful data analysis. It includes database design, sample data, relationships between tables, and analytical SQL queries.

## 🗂️ Database Tables

- **Departments** – Department details, location, budget, staff, and head doctor.
- **Doctors** – Doctor information, specialization, experience, department, and status.
- **Patients** – Patient details, medical information, admission/discharge details, and insurance.
- **Appointments** – Patient appointments, doctors, diagnosis, purpose, and status.
- **Bills** – Billing details, discounts, insurance claims, payment modes, and payment status.
- **Medications** – Prescribed medicines, dosage, frequency, dates, and status.

## 🔍 SQL Concepts Used

- Database & Table Creation
- Primary and Foreign Keys
- INSERT, UPDATE and SELECT
- JOINs
- Aggregate Functions
- GROUP BY and HAVING
- Subqueries
- Views
- Window Functions
- Triggers
- Data Analysis

## 📊 Analysis Performed

The project includes queries for analyzing patients, doctors, departments, appointments, billing and revenue. It also identifies top patients, department revenue, doctor-wise earnings, payment modes, and city-wise rankings.
